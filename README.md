# Maximo

The Max Birds content pack is in [`assets/`](assets/README.md): 24 PNG images, a static [preview](assets/preview.html), a [manifest](assets/manifest.json), and the generation prompts. The pack follows Pirots 3 art direction and includes the bright daytime canal-side neighbourhood background.

The purple photographic gem is pending a fourth distinct Max source photo. This repository currently contains image assets; game logic and animation are not included.
